# MegaMedStom Astana — презентационная версия интернет-магазина

Интернет-магазин стоматологических материалов, инструментов и оборудования
(г. Астана, ул. Айнакол, 66). Сделан под телефон: поиск, каталог, корзина,
«Список закупки» для клиник, оформление без регистрации и отправка заказа
менеджеру в WhatsApp.

**Важно (для владельца и разработчика):** ассортимент и цены — презентационные,
фотографии товаров — стоковые изображения (подробности в разделе 3). Пометки
«демонстрационная версия» со страниц сайта убраны — покупатель видит обычный
магазин, служебные пояснения остались только в этом файле. Никаких выдуманных
скидок, «осталось 2 штуки», рейтингов и фальшивых оплат на сайте нет. Оплата —
только после подтверждения менеджером, заказ уходит в WhatsApp.

## 1. Как открыть и показать

**Вариант А (рекомендуемый).** Двойной клик по `start.bat` — запустится локальный
сервер и откроется браузер на `http://localhost:8788`. Нужен установленный
[Node.js](https://nodejs.org) (LTS). Чтобы остановить — закройте окно консоли.

Показать с телефона: пока окно консоли открыто, в нём будет напечатан адрес вида
`http://192.168.x.x:8788` — откройте его на телефоне в той же Wi-Fi сети
(Windows может один раз спросить разрешение брандмауэра — разрешите).

**Вариант Б.** Просто двойной клик по `index.html`. Всё работает без сервера:
сайт целиком статический, состояние хранится в браузере (localStorage).

Пароль панели менеджера: **admin2026** (ссылка «Панель менеджера» в футере).
Пароль хранится в коде (`js/base.js`) и годится только для показа; в рабочей
версии обязательна серверная авторизация.

## 2. Что уже работает (полный список)

**Покупателю**
- Каталог: 10 категорий и подкатегории, 64 позиции витрины, бренды, сортировки
  (популярные, цена ↑/↓, название, новинки), фильтры по цене/бренду/наличию,
  ссылки-фильтры в адресной строке (можно отправить ссылку коллеге).
- Поиск: по названию, бренду, артикулу и синонимам («заморозка» найдёт
  анестезию, «пломба» — композиты). Подсказки, история запросов.
- Карточка товара: варианты (оттенки/размеры), количество, «В корзину»,
  «В список закупки», «Купить в один клик», характеристики, доставка.
  Позиции «Цена по запросу» — с кнопкой «Запросить стоимость» в WhatsApp.
- Корзина: сохраняется между заходами, меняется количество, есть кнопка
  «Отправить в WhatsApp» (черновик заказа).
- Оформление без регистрации: имя, телефон, email, самовывоз / доставка по
  Астане / по Казахстану, «Заказ для клиники» с БИН, комментарий, согласие.
  Валидация, защита от двойного нажатия.
- После заказа: номер вида `MMS-ДДММГГ-XXXX`, статусы (Новый → Подтверждён →
  Собирается → Отправлен → Завершён / Отменён), кнопки WhatsApp и «Позвонить».
- «Список закупки» для клиник: собирайте позиции (включая «по запросу»),
  кнопка «Добавить стартовый набор кабинета», «Запросить счёт в WhatsApp».
- Избранное, кабинет покупателя: история заказов, «Повторить заказ»,
  сохранённые данные, экспорт/удаление своих данных.
- Виджет «Помощь с подбором»: подключён к ИИ (Groq) и отвечает **только по
  данным каталога** — рекомендует реальные позиции со ссылками, не выдумывает
  цены и не даёт клинических советов. Если внешний сервис недоступен или
  исчерпан бесплатный лимит, виджет незаметно отвечает встроенным подбором по
  каталогу — посетитель в любом случае получает карточки товаров.

**Менеджеру (панель менеджера, пароль admin2026)**
- Заказы: список, смена статуса в один тап, кнопка «Клиенту» (WhatsApp-сообщение).
- Товары: правка названия и цены прямо в таблице (включая снятие цены в
  «по запросу»), отметка «Новинка», сброс правок.
- Данные: экспорт/импорт JSON, полный сброс данных.

**Технически**
- Мобильная вёрстка 360–430px без горизонтального скролла (проверено на
  360/390/430), десктоп — от 900px и шире (проверено на 1280).
- Доступность: skip-ссылка, aria-подписи, фокус, поддержка reduced-motion.
- SEO: `sitemap.xml`, `robots.txt`, canonical, JSON-LD (Organization, Product,
  BreadcrumbList), осмысленные title/description, страницы политики.

## 3. Что презентационное и как это станет настоящим

| Сейчас (презентация) | В рабочей версии |
|---|---|
| 64 товара в `js/data.js`, цены презентационные | Ваш прайс из Excel/CSV (заменим) |
| Фото стоковые, 64 шт. в `images/products/` | Ваши реальные фото товаров |
| Заказы в браузере (localStorage) | База данных на сервере, общие для всех устройств |
| Панель менеджера с паролем в коде | Серверная авторизация, роли, журнал действий |
| Ссылка «Панель менеджера» в футере видна всем | Спрятать или оставить только для сотрудников |
| Домен `megamedstom.kz` в SEO-файлах | Заменить на фактический домен |

**Фотографии и лицензии.** Фото товаров скачаны из Unsplash и Wikimedia Commons
(свободные лицензии, коммерческое использование разрешено). Файлы лежат в
`images/products/` с именами по id товара (например, `comp-001.jpg`), размер
900×900. Часть снимков шприцов обновлена на более понятные: `art-001`,
`art-002`, `syr-001`, `shr-001` (шприцы и карпулы), `end-006` (файлы),
`comp-002` (композит), `bond-001` (адгезив), `etch-001` (гель) — источники
те же, Wikimedia Commons. При запуске замените все фото реальными — файлом
с тем же именем или через поле `img` в каталоге.

**Замена каталога.** Все товары лежат в одном файле `js/data.js`. У каждого
товара простые поля: `id`, `name` (название), `article` (артикул), `brand`,
`price` (число или `null` = «по запросу»), `unit` (фасовка), `cat`/`sub`
(категория), `variants` (оттенки/размеры), `specs` (характеристики), `img`
(фото). Правки цен можно вносить и без кода — в панели менеджера, раздел
«Товары».

**WhatsApp.** Уже сейчас указывает на ваш номер +7 771 544 24 87. В рабочей
версии к нему можно подключить WhatsApp Business API или CRM, чтобы заказы и
переписка собирались в одном окне.

**Оплата.** На сайте её сознательно нет — так и должно быть: счёт для клиник по
БИН, оплата после подтверждения (наличные/перевод) или Kaspi QR — по вашему
решению, добавим на этапе продакшена.

**AI-консультант (Groq).** Виджет «Помощь с подбором» подключён к сервису Groq
(модель `qwen/qwen3.8-27b`, JSON-режим): он получает компактный слепок каталога
и отвечает только по нему — без выдуманных товаров, цен и сроков; на вопросы о
лечении вежливо отказывает. **Ключ в статическом сайте не хранится:** в
`js/base.js` (раздел `MMS.CONFIG.ai`) стоит `enabled: false`, поэтому сейчас
виджет отвечает встроенным подбором по каталогу. Для полноценного ИИ-режима
нужен прокси на сервере: ключ хранится там, а в `MMS.CONFIG.ai` достаточно
указать `enabled: true` и адрес прокси. Бесплатный тариф Groq ограничен
(~7 000 токенов в минуту: это примерно два вопроса подряд, далее пауза до
минуты) — при отказе API виджет автоматически подбирает товары встроенным
поиском по каталогу.

## 4. Файлы проекта

```
index.html, catalog.html, product.html      — главная, каталог, товар
cart.html, checkout.html, success.html      — корзина, оформление, «заявка принята»
favorites.html, profile.html                — избранное, кабинет («Мои заказы» + «Список закупки»)
admin.html                                  — панель менеджера (пароль admin2026)
about.html, delivery.html, returns.html,
privacy.html, terms.html                    — информационные страницы
404.html                                    — страница «не найдено» (показывается на любом несуществующем адресе)
css/base.css                                — дизайн-система (цвета, типографика, компоненты)
css/shop.css                                — стили страниц
js/base.js                                  — данные компании, форматирование, иконки
js/art.js                                   — запасные векторные иллюстрации (если у товара нет фото)
js/data.js                                  — КАТАЛОГ (категории, товары, бренды, синонимы)
js/store.js                                 — состояние: корзина, избранное, заказы (localStorage)
js/search.js                                — поиск, фильтры, сортировка
js/ui.js                                    — шапка, карточки, шторки, тосты, WhatsApp-тексты
server.js, start.bat                        — локальный предпросмотр
robots.txt, sitemap.xml, images/            — SEO, favicon; images/products/ — фото товаров
```

**Передача разработчику (следующий этап).** Макет и логика готовы к переносу на
серверный стек: Next.js/Node + PostgreSQL, заказы в БД, авторизация админки,
импорт прайса из 1С/CSV, уведомления о заказах. Дизайн-токены, структура
каталога и все пользовательские сценарии уже зафиксированы в этом прототипе —
переписывать «с нуля» ничего не придётся.

## 5. Что проверено перед передачей

- Поиск (включая синонимы), фильтры, ссылки с фильтрами, «Показать ещё».
- Карточка товара: варианты, количество, добавление в корзину и список закупки.
- Корзина: изменение количества, удаление, сохранение между заходами.
- Оформление: валидация полей, заказ для клиники с БИН, доставка, согласие;
  полный цикл «заказ → success → статус меняет менеджер → кабинет покупателя».
- Избранное, «Повторить заказ», «Стартовый набор кабинета», экспорт данных.
- Фото товаров: все 64 изображения отображаются на страницах (главная, каталог,
  товар, корзина, оформление, поиск, избранное, кабинет, панель менеджера).
- Панель менеджера: вход по паролю, смена статуса, правка цены (и её сброс), экспорт.
- Мобильные ширины 360/390/430 — без горизонтального скролла; десктоп 1280 —
  шапка в одну строку, сетки 3–5 колонок.
- Главная: компактный первый экран с поиском (сразу ведёт в каталог),
  «упакованные» категории (2 колонки на телефоне) и короткий путь до товаров;
  лишние кнопки и дублирующие блоки убраны.
- Виджет «Помощь с подбором»: проверены ответы ИИ (товары, доставка, оплата,
  оформление) и корректный отказ на клинические вопросы.
- Работает по `http://localhost:8788` и двойным кликом по `index.html` (то есть
  и без сервера, и без интернета — шрифт подставится системный).

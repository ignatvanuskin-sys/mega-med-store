Политика конфиденциальности

Коротко

Сайт собирает только те данные, которые нужны для оформления заказа: имя, телефон, email, организация и адрес доставки — если вы их указали. Данные используются только для связи по заказу и не передаются третьим лицам.

Что хранится и где

  • Корзина, избранное, «Список закупки», заказы и история поиска — в локальном хранилище браузера (localStorage) на вашем устройстве;
  • Данные исчезнут, если очистить данные сайта в браузере;
  • Удалить всё можно в любой момент: кабинет → «Удалить сохранённые данные».

Зачем нужны данные

  • Чтобы менеджер подтвердил заказ, наличие и условия доставки;
  • Чтобы оформить счёт для клиники (название организации, БИН);
  • Чтобы связаться с вами по статусу заказа.

Передача данных

Заказ передаётся менеджеру через WhatsApp — на этот канал распространяются правила WhatsApp. Мы не продаём и не передаём ваши данные третьим лицам для рекламы.

В рабочей версии

После запуска на сервере данные будут обрабатываться в соответствии с законодательством Республики Казахстан: хранение на защищённом сервере, доступ только сотрудникам, право на удаление по запросу через контакты магазина.

Политика может обновляться — актуальная редакция всегда доступна на этой странице.
